# Deploying GCP Minecraft On-Demand

Welcome! This interactive guide will deploy your own cost-optimized, scale-to-zero Minecraft server on Google Cloud Platform (GCP).

Since you are running inside Google Cloud Shell, the repository is already cloned and your session is authenticated to your Google account. Let's get started!

Set your active GCP Project ID in the terminal:

1. Copy and modify the command to use your actual GCP Project ID (e.g., `my-minecraft-project`):
   ```bash
   gcloud config set project YOUR_PROJECT_ID
   ```

2. Enable the required GCP service APIs:
   ```bash
   gcloud services enable \
     compute.googleapis.com \
     cloudfunctions.googleapis.com \
     pubsub.googleapis.com \
     dns.googleapis.com \
     secretmanager.googleapis.com \
     cloudbuild.googleapis.com
   ```

## ⚙️ Step 2: Run Setup Wizard

We provide an interactive script to enable project settings and configure your administration passcode and Discord webhook:

1. Run the setup wizard:
   ```bash
   # Make the setup script executable
   chmod +x scripts/linux/setup.sh
   # Run the interactive wizard
   ./scripts/linux/setup.sh
   ```

Follow the prompts. The wizard automatically validates your inputs, checks your project authentication, and generates your secure `terraform/terraform.tfvars` configuration file.

---

## 🚀 Step 3: Deploy Infrastructure (Terraform)

With your environment variables set, we can deploy the stack:

1. **Initialize Terraform:**
   This downloads the GCP provider and state backend:
   ```bash
   cd terraform && terraform init
   ```

2. **Deploy the stack to Google Cloud:**
   ```bash
   terraform apply
   ```

*Note: The apply process takes around 2-3 minutes. Make sure to type `yes` to confirm when prompted, and keep the DNS nameserver outputs handy!*

---

## 🌐 Step 4: Delegate Domain Nameservers

To enable the event-driven autostart feature (where resolution queries wake up the server), delegate DNS authority of your subdomain (e.g., `mc.yourdomain.com`) to GCP:

* Find the `dns_nameservers` output list generated by Terraform.
* Log into your domain registrar (GoDaddy, Namecheap, Cloudflare, etc.).
* Add four separate **NS Records** in your domain settings:
  * **Type:** `NS`
  * **Name/Host:** `mc`
  * **Value/Target:** The name servers provided by the Terraform output.
